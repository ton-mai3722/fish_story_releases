# Fish Story (เล่าเรื่องปลา) 🐟🫧

**Fish Story** is a modern aquarium and aquatic ecosystem tracker mobile application built with Flutter. Designed for passionate aquarists, it provides comprehensive fish profiling, growth diaries, water parameter tracking, tank maintenance schedules, and hardware budget analytics with a fluid **Apple Liquid Glass (Frosted Glassmorphism)** user interface.

## 🎯 Key Features

### 1. 🪟 Apple Liquid Glass (iOS Frosted Acrylic Glassmorphism)
- **Fluid Visual Hierarchy**: Translucent frosted panels (`BackdropFilter` Gaussian blur), specular highlights, and soft gradient ambient mesh.
- **Modern 3D Transparent App Icon**: High-fidelity 3D fish skeleton icon designed for modern mobile launchers.
- **Glass Segmented Control**: Seamless switching between **Fish Projects** (โปรเจกต์ปลา) and **Tanks & Ponds** (ตู้และบ่อเลี้ยง).

### 2. 🌐 Bilingual Internationalization (TH 🇹🇭 / EN 🇺🇸)
- **JSON-Driven Localization**: Fast, type-safe dictionary lookup supporting Thai and English runtime switching.
- **Persistent Locale Preference**: Saved seamlessly across app launches with `SharedPreferences`.
- **Liquid Glass Language Toggle**: Minimalist glass pill toggle accessible on both Login and Home screens.

### 3. 🐠 Tank & Aquatic Habitat Tracker
- **Dual Media Pipeline**: Full support for both Google Drive CDN links and direct Base64 Data URI photo rendering.
- **Volume & Metric Calculators**: Automatic water capacity calculation (Liters & Gallons) from tank dimensions.
- **Cycling & Lifespan Counters**: Real-time counter of days running since tank establishment.
- **Multi-Category Habitats**: Fresh water, Marine, Planted Aquascapes, Axolotls, and Ponds.

### 4. 📝 Growth Diary & Timeline
- **Multi-Photo Change Logging**: Attach photos taken directly with the phone camera or selected from gallery.
- **Water Change & Maintenance Analytics**: Track percentages, water parameter changes, and equipment additions.
- **Cloud Firestore Synchronization**: Instant cloud synchronization between Mobile App and Web CMS.

## 🏗 Technology Stack

- **Framework**: Flutter 3.44.x (Dart 3.10+)
- **Architecture**: BLoC / Cubit State Management + Clean Architecture
- **Backend / Cloud**: Cloud Firestore, Firebase Auth, Google Drive Direct CDN
- **Web Companion**: Next.js 16 (Turbopack) Fish Story CMS
